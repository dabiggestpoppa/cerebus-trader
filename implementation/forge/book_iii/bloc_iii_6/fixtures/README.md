# III.6 golden fixtures

Deterministic, synthetic structural fixtures for the intelligence API and
snapshot service. Generated by `generate.py` from `_builders.py`, which uses
the ratified III.1–III.5 types to construct inputs and the III.6 composer to
project them.

## Provenance labels

- `SYNTHETIC_FIXTURE` — constructed inputs; no market data was observed.
- `CANONICAL_SOURCE_SLICE` — identifiers, statuses and parent references
  copied verbatim from the canonical setup corpus (`corpus/canonical/setups/`).

## Files

| File | Case | Expectation |
|---|---|---|
| `consistent_eur_snapshot.json` | EUR L1 consistent snapshot | deterministic id/hash, all sections present |
| `model_only_no_setup.json` | model-only projection | `setup` section `UNAVAILABLE` with reason |
| `stand_down_lock.json` | active stand-down | lock preserved, no-go carried |
| `missing_provider.json` | provider seam unset | `PROVIDER_NOT_CONFIGURED` refusal |
| `data_quality_failure.json` | blocked input quality | `DATA_QUALITY_BLOCKED` refusal |
| `research_only_fib.json` | Fib rekey | `RESEARCH_ONLY`, research surface only |
| `manual_jpy.json` | JPY role gate | `MANUAL_OPERATOR`, no automation |
| `xau_watch_ceiling.json` | XAU quarter-zone | `WATCH` ceiling preserved |
| `historical_version_mismatch.json` | pinned version drift | `VERSION_DRIFT` refusal |
| `card_schema_incompatibility.json` | strict machine card | `SCHEMA_INCOMPATIBLE` refusal |
| `restricted_exposure.json` | anonymous operator-only | uniform denial, no ids |
| `deterministic_reconstruction.json` | retained replay | replayed hash equals recorded hash |

`FIXTURE_MANIFEST.json` records LF-normalised SHA-256 for every fixture.
`FROZEN_BASELINE.json` records the module count and aggregate hash of the five
ratified upstream packages; `tests/test_forge_intelligence_api.py` verifies
both so upstream drift cannot pass unnoticed.

## Limits

Reproduction proves determinism of the projection, not market accuracy,
historical performance, provider readiness or production fitness. No fixture
may be restated as current market intelligence or as a performance claim.
