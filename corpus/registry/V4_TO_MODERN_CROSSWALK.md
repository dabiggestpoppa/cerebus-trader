## Intellectual progression
V4 was not a dead end. Its strongest concepts progressively changed form:

constraint window
-> tier/native scale
-> activation event
-> repeated transition evidence
-> checkpoint conditioning
-> failure/repair
-> state age
-> first delivery
-> recursive path
-> nested scale
-> conditional distribution
-> asset-native modern models.

The modern doctrine removes deterministic language and asks conditional questions:
Given scale, clock, state, path consumed, event family and remaining distribution, what outcomes remain available and with what evidence?

## FORGE usage
Ask CEREBUS should be able to answer both:
- "What did P90 mean in v4?"
- "What is the modern descendant of P90P?"

It must never silently substitute one generation's thresholds/statistics for another.
