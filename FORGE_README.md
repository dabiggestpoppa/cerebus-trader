# GLX FORGE — Corpus Branch

This branch is the staging ground for **GLX FORGE Book I: CEREBUS Corpus**.

The objective is preservation and organization of the complete CEREBUS/GLX market-research corpus before product architecture is frozen.

## Rule

**Recover first. Classify second. Canonicalize third. Productize last.**

Nothing is deleted merely because it is old. Superseded models, negative tests, abandoned setup families, old indicator revisions, scientific PDFs, result CSVs, infographics, manuals, and conversation-derived findings are preserved with lineage.

## Current structure

- `corpus/registry/` — recovery and provenance registry
- `corpus/specs/` — frozen model specifications
- `corpus/indicators/` — verbatim indicator source recovered from Library
- Additional raw data, results, scientific papers, manuals, visuals and conversation-derived records will be added during Book I recovery.

See `corpus/registry/BOOK_I_CORPUS_RECOVERY_REGISTRY.md` for the live recovery map.
