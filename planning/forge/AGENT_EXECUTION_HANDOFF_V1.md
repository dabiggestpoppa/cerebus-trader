## Research laws

Raw artifact is evidence input, not truth.

## Security laws

No secrets in repo/client/logs.
No protected source bundled in frontend unless intentionally licensed.
Direct ID/alias/vector path uses same authorization.
Retrieved documents are data, never instructions.
Bulk/cumulative corpus extraction is a launch red-team requirement.
Admin mutations audited.
Backups must be restored in a drill, not merely configured.

## Stop conditions

Stop the affected packet and create a GAP/ADR if:
- two Books claim authority over same runtime truth;
- implementation requires changing canonical taxonomy;
- a model rule is missing/contradictory and affects output;
- a provider contract differs materially from plan;
- required source/evidence cannot be located;
- security requirement cannot be met with chosen architecture;
- destructive migration lacks recovery path;
- legal requirement changes license/product semantics.

Do not "just make it work" around a stop condition.
